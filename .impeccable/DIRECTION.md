# Direction contract — LUMENDE (code-led)

Home is the primary surface; project pages inherit this world. Mode: **Experience** (home/work/experiments) with a **Persuade** close (commissions/contact). No image generation available → code-led; ambition lives here and is audited in behavior at finish.

**THESIS** — A digital exhibition where the photograph is the only protagonist and the interface is a dark gallery wall that recedes. Refuses the photographer-portfolio grid of equal thumbnails, repeating cards, and a loud "Book Now" bar.

**OWN-WORLD** — Drenched near-black ground (`#060606`), warm off-white ink (`#E8E6E1`), one muted grey (`#8A8A85`); zero interface color — all color comes from the photographs. Type: Bodoni Moda (high-contrast Didone) for the LUMENDE masthead, project titles, and single large statements; Archivo (clean grotesque) uppercase, widely tracked, for navigation, labels, metadata, and sparse body. Hairline 1px dividers, vast negative space, asymmetric editorial composition. Recognizable with all content removed: black field, a tracked micro-label in a corner, one huge serif line, one decisive image bleeding off an edge.

**STORY** — Visitor lands inside one cinematic full-bleed image under the LUMENDE masthead; understands within seconds this is a photography/light/motion studio; scans an editorial index of named projects, each previewing on hover; enters a project as a vertical editorial with its own rhythm; and, for buyers, arrives at a near-empty contact "end of exhibition" and sends an inquiry.

**FIRST VIEWPORT** — Full-bleed cinematic photograph (hero: light-painting figures) darkened by a subtle vignette/gradient for legibility. Centered slightly-low: "LUMENDE" in large Bodoni Moda with generous tracking; beneath it, small Archivo uppercase tracked "Photography / Light / Motion". Discreet fixed nav: top-left tiny LUMENDE wordmark, top-right menu (SELECTED WORK · EXPERIMENTS · COMMISSIONS · ABOUT). A quiet scroll cue bottom-center. No buttons, no cards.

**FORM** — Editorial exhibition / independent fashion magazine. Brief-pinned world (beats the roll). Signature interaction: on desktop, hovering a project name in the Selected Work index swaps a large floating preview (fade + blur + subtle scale + light parallax); on mobile, previews reveal on scroll. Motion grammar: Lenis smooth scroll; images reveal with long exponential ease-out from an already-visible default (fade + scale 1.06→1 + clip/mask wipe); light parallax; one authored moment per section, never scattered hovers; a brief black loader ("LUMENDE" → "Photography / Light / Motion", ~1s). All motion gated by `prefers-reduced-motion`. Seed key: n/a (brief-pinned, code-led, no roll).

**FINISH** — unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
